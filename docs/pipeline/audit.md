## Критично (P1)

- **П-1. Новый вопрос посреди стрима блокируется лимитом параллельности** (`manager.ts` applyQuestion/canStart, `budget.ts`). `abort()` асинхронный, `budget.inflight` падает позже, `canStart` в том же тике видит `2 ≥ maxConcurrent=2` → `blocked`, состояние навсегда `generating`. Штатный тест проходил из-за `maxConcurrent: 4`.
- **П-2. Fallback уходит в облако без `consent.cloud`** (`manager.ts` ветка fallback). Проверено зондом: локальный провайдер падает → облачный с `allowFallback` получает CV и транскрипт.
- **П-3. AC-7 FAIL.** whisper base b5454, медиана 5 прогонов: auto 1290–1402 мс, язык зафиксирован 883–983 мс. Дефолт `language:'auto'`, фиксация только после первой уверенной реплики; замера в логе диагностики нет; отклонение нигде не принято.
- **П-4. Второй запуск exe помечает живую сессию `interrupted`** (`index.ts`: после `app.quit()` модуль продолжает, `new Db` + `recoverInterrupted` + миграции во втором процессе).

## Стоит починить (P2)

- **P2-1** `errors.ts` берёт `detail` из тела ответа как есть → ключ (эхо провайдера) в снапшоте и оверлее.
- **P2-2** после stop/panic статусы mic/system остаются `ok`.
- **P2-3** статус LLM `ok` по наличию роли, без проверки; защита экрана — «выкл.» до создания оверлея, «включена» по номеру сборки; диагностика ссылается на несуществующий мастер проверки.
- **P2-4** prompt-injection: `section`/`docName` чанка не ограждаются; `</ cv>` и полноширинные `＜/cv＞` проходят; вопрос собеседника и изображение не объявлены недоверенными, `"` не экранируется.
- **P2-5** удалённая сессия остаётся в WAL (нет `secure_delete`/checkpoint).
- **P2-6** `consent.screen` не проверяется.
- **P2-7** онбординг ставит `consent.mic/system` при показе шага, `cloud: c.cloud || !local`.
- **P2-8** фиксация языка по первой реплике переводит речь на другом языке (`language=en` на русской фразе → английский «перевод»).
- **P2-9** SHA256 бинарника whisper проверяется, только если ответил GitHub API; tessdata не проверяется.

## Наблюдения (P3)

- P3-1 редирект с loopback обходит офлайн (`guard.ts` проверяет только исходный URL).
- Блокировки CSP в renderer не логируются; тип записи не `blocked_offline`.
- Для текстового вопроса `endMs=0` → свежий транскрипт отрезается фильтром контекста.
- `chunkText`: строка > 700 символов без пробелов теряется частично.
- `retry-after` игнорируется; после первого токена нет таймаута простоя стрима.
- `whisper-server` живёт после остановки сессии (≈ 280 МБ WS); всего после сессии 907 МБ WS.
- История — максимум 50 сессий без пагинации; дневной бюджет не сбрасывается в полночь.
- Мёртвый код: `AnswerBoard.owns`, `QuestionCoordinator.setOptions`; коды `asr_unavailable`/`device_unavailable` не выставляются.
- Расхождения contracts.md с кодом: нет `testConnection`, профили (`notes` вместо `answer_lang/extra`), `overlay.pinned` вместо `clickThrough`, `captureMic/captureSystem`, generic `invoke`, нет `providers/router.ts`, `renderer/audio/*`, лишнее `consent.participants`.
- Не проверено: Ollama `*:cloud` считается локальной; Anthropic `output_config/betas/fallbacks` без ключа.
