# Project Brief: Kairos M

Рабочее имя по ТЗ — MagerCopilot. Новое имя — **Kairos M**. Кайрос — греческое «тот самый момент»,
ведь продукт должен вовремя поймать актуальный вопрос. «M» стоит отдельно, как индекс модели, и читается как
Moment / Meeting. Идентификатор в коде — `kairos-m`, app id — `app.kairos-m`.

## Суть
Локальное десктопное приложение для Windows: слушает микрофон и звук собеседника раздельно,
распознаёт речь локально, вовремя замечает актуальный вопрос и показывает в маленьком
оверлее короткий и проверяемый ответ, привязанный к фактам из CV/JD. Модель — BYOK
(свои ключи OpenAI / Anthropic / Gemini / AnyModel / Ollama / любой OpenAI-compatible).
Аккаунт и свой сервер не нужны. Успех — пользователь за ≤ 3 минуты от первого запуска получает
корректный ответ на сказанный вслух вопрос, и приложение не врёт о статусах (захват, API,
защита экрана, офлайн).

Пожелание пользователя (2026-10-27): «максимально быстро, качественно, конфиденциально и удобно
для среднего пользователя». Отсюда приоритеты: локальное по умолчанию, минимум настроек на старте,
понятные русские тексты ошибок, быстрый Say-it ответ раньше подробного.

## Пользователь и сценарий
IT-кандидаты, разработчики, менеджеры, люди на неродном языке. Запуск вручную перед
тренировкой / интервью / встречей. Режимы: тренировка (mock), live-подсказки
(разрешённые), встреча (только транскрипт + итог).

## Скоуп
**В скоупе (P0 ТЗ):** раздельный захват mic + системного звука; локальная ASR (whisper.cpp sidecar);
partial/final транскрипты; кнопка «Ответить» + отключаемый автодетектор вопросов; версионирование
вопросов с отменой устаревших; 6 типов провайдеров; BYOK с секретами в DPAPI; оверлей compact/expanded
без кражи фокуса; ручной захват области экрана с превью; CV/JD-контекст с локальным поиском;
глобальные хоткеи; локальная история в SQLite; диагностика; лимиты бюджета; офлайн-режим
с блокировкой внешних вызовов; восстановление после сбоя; онбординг.

**Вне скоупа (non-goals):** обход прокторинга/античита/EDR, скрытие процесса, вмешательство в
Zoom/Meet/Teams, автоввод ответа за пользователя, обещание «100% невидимости»; macOS/Linux;
облачный аккаунт и hosted-план; подписанный установщик с автообновлением (P1 — нужен сертификат);
speaker diarization внутри remote-канала (P1).

## Стек и окружение
Windows 11 x64, Node 24. Rust/MSVC на машине нет, поэтому хост — **Electron** (ТЗ допускает его после спайка,
см. spikes/FINDINGS.md S1 и decisions.md). UI: React 19 + TypeScript + Vite (electron-vite).
Хранилище: SQLite (`node:sqlite`). Секреты: Electron `safeStorage` (DPAPI). ASR: whisper.cpp
`whisper-server.exe` как sidecar на 127.0.0.1 (S2). Тесты: Vitest.

## Внешние зависимости
- OpenAI API (`/v1/chat/completions`, `/v1/models`), Bearer-ключ.
- Anthropic Messages API (`/v1/messages`, SSE, `x-api-key`, `anthropic-version: 2023-06-01`).
- Gemini API (`/v1beta/models/{m}:streamGenerateContent?alt=sse`, `x-goog-api-key`).
- AnyModel (`https://anymodel.org/v1`, OpenAI-compatible).
- Ollama (`http://127.0.0.1:11434/v1`, без ключа).
- whisper.cpp prebuilt (MIT), модели ggml с Hugging Face (MIT), с проверкой SHA256.

## Ограничения и риски
- Защита оверлея от захвата (WDA_EXCLUDEFROMCAPTURE) — не гарантия; работает не со всеми методами захвата → честный статус + мастер проверки (дизайн).
- Partial-транскрипты на whisper (не стриминговая модель) делаются перераспознаванием растущего буфера → проверено спайком S2 по задержке.
- Электрон тяжелее Tauri по RAM → замер в S1, цель ≤ 250 МБ простоя.
- Путь проекта в OneDrive с кириллицей → рантайм-данные и модели в `%APPDATA%/kairos-m` (ASCII).
- Реальные облачные провайдеры не проверить без ключей пользователя → контрактные тесты на mock-SSE + живой тест Ollama.

## Как запускать
Проверено 2026-10-27/28 на Windows 11, Node 24.15, Electron 45.1.

```powershell
npm install                 # один раз
npm run typecheck           # tsc без ошибок
npm test                    # vitest: 80 тестов (провайдеры на mock-сервере, координатор, менеджер сессии, хранилище, импорт PDF/DOCX, prompt-injection)
npm run dev                 # разработка с HMR
npm run build               # сборка в out/
npx electron .              # запуск собранного out/ (то, на чём проверялся слайс)
npm run dist:dir            # распакованная сборка: release/win-unpacked/Kairos M.exe
npm run dist                # NSIS-установщик в release/
npm run icon                # пересоздать resources/icon.ico|png
```

- Данные: `%APPDATA%/kairos-m` (settings.json, providers.json, secrets.bin под DPAPI, kairos.db, asr/, ocr/).
- ASR ставится из приложения (Онбординг → «Распознавание» или Настройки → «Речь и звук»): whisper.cpp b5454 + модель с проверкой SHA256.
- Локальный путь без ключей: Ollama на `127.0.0.1:11434` + любая instruct-модель (проверено на `qwen2.5:14b-instruct-q5_K_M`).
- Отладка UI: `npx electron . --remote-debugging-port=9333` → страницы index/overlay/picker доступны по CDP.

Замеры слайса (эта машина, CPU-профиль whisper base, Ollama qwen2.5 14B на RTX 5070 Ti):
- текстовый вопрос → первый токен 0.36–0.43 с, Say it + тезисы ≈ 3 с;
- голос (TTS-фраза 7 с) → вопрос в UI 2.8 с, первый токен 3.0 с (режим авто, ASR 1.34–1.37 с); с явным языком ASR 0.88–0.98 с (аудит);
- снимок области → OCR (eng+rus+ukr) → разбор условия ≈ 15 с;
- холодный старт локальной модели 20–30 с: сглаживается прогревом при старте сессии.

## Глоссарий
- **Say it / Talking points / Deep dive** — три шаблона ответа (фраза 15–35 слов / 3–5 тезисов / подробно).
- **source user|remote** — канал: микрофон пользователя / системный звук собеседника.
- **revision** — версия текста вопроса; ответ на старую ревизию не может заменить новый.
