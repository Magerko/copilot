# Выпуск 0.1.0 (локальная сборка)

Дата: 2026-10-28. Публичного выката нет: приложение десктопное, без сервера; сборка лежит у пользователя.

## Что собрано
- `release/Kairos M Setup 0.1.0.exe` — NSIS-установщик, 145 МБ, x64, установка в профиль пользователя, выбор каталога.
- `release/win-unpacked/Kairos M.exe` — распакованная сборка, запускается без установки.
- Без подписи кода: SmartScreen покажет «Неизвестный издатель» → «Подробнее → Выполнить в любом случае». Подпись — P1 (нужен сертификат).

## Чем проверено
- `npm run typecheck` — 0 ошибок; `npm test` — 80/80.
- Живой срез до аудита на собранном exe: текстовый вопрос → первый токен 0.43 с (Ollama qwen2.5 14B).
- Аудит свежим контекстом (`audit.md`): 4 критичных и 9 значимых находок; все исправлены, кроме перечисленных ниже, каждая — тестом или замером.
- После фиксов аудита GUI не запускался (T-34): изменения UI — онбординг (согласия, язык разговора) и статусы.

## Известные ограничения
- Память: ≈ 450 МБ в простое (Electron) против цели 250 МБ; whisper-server ≈ 280 МБ во время сессии, гасится через 3 мин после неё (T-17).
- Защита окна подсказок от захвата — флаг Windows, работает не со всеми программами; статус честно жёлтый.
- Облачные провайдеры проверены на mock-серверах; с реальными ключами — у пользователя.
- Захват звука отдельного приложения не поддерживается: только весь звук Windows.
- Ollama-модели `*:cloud` пока считаются локальными (T-32).

## Данные и откат
- Данные: `%APPDATA%/kairos-m`. Деинсталлятор их не удаляет (`deleteAppDataOnUninstall: false`): переустановка или откат сохраняют ключи, профили и историю.
- Откат — удалить через «Приложения Windows» и поставить предыдущий установщик. Полный сброс — удалить `%APPDATA%/kairos-m` (ключи провайдеров тоже исчезнут).
- Ключи зашифрованы DPAPI под учётной записью Windows: при переносе на другой ПК их нужно ввести заново.
