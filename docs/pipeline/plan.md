# План

## Шаги
1. **Каркас и хранилище** — Electron + React, два окна (Dashboard, Overlay) + трей, SQLite с миграциями, секреты через DPAPI. Готово = AC-1, AC-2, AC-9.
2. **Провайдеры и роутинг** — адаптеры OpenAI / Anthropic / Gemini / OpenAI-compatible (AnyModel, Ollama, LM Studio…), нормализованные ошибки, отмена, стриминг, бюджет и лимиты. Готово = AC-3, AC-4, AC-10.
3. **Ядро разговора** — state machine, детектор вопросов, версионированный координатор запросов, контекст (скользящее окно + CV/JD-поиск), промпт-пресеты. Готово = AC-5, AC-6.
4. **Аудио и ASR** — mic + loopback раздельно, VAD, ресемпл 16 кГц, whisper-server sidecar, partial/final сегменты, индикаторы уровня. Готово = AC-7.
5. **Оверлей, хоткеи, экран** — compact/expanded без кражи фокуса, защита отображения со статусом, глобальные хоткеи, захват области с превью и vision/OCR-фолбэком. Готово = AC-8, AC-11.
6. **Доверие и UX** — онбординг ≤ 3 мин, офлайн-режим с сетевой блокировкой, история/удаление, диагностика, восстановление после сбоя, экспорт Markdown/JSON. Готово = AC-12, AC-13, AC-14.

## Acceptance criteria
AC-1: Дано — чистый профиль. Когда — `npm run dev` (или собранный exe). Тогда — открываются Dashboard и трей; оверлей показывается хоткеем без смены foreground-окна (проверка скриптом GetForegroundWindow до/после).

AC-2: Дано — сохранён ключ провайдера. Когда — поиск строки ключа (grep) по `%APPDATA%/kairos-m` (sqlite, json, логи) и экспорту сессии. Тогда — 0 вхождений; ключ читается только через safeStorage; удаление провайдера стирает секрет.

AC-3: Дано — mock-серверы, имитирующие SSE каждого из 4 протоколов. Когда — `npm test`. Тогда — для каждого адаптера: стрим склеивается в текст, `cancel()` обрывает запрос, 401/402/429/5xx/таймаут мапятся в `ProviderError.code`, 429/5xx — ≤ 2 ретрая с backoff.

AC-4: Дано — запущенный Ollama с моделью `qwen2.5:14b-instruct-q5_K_M`. Когда — «Проверить соединение» и вопрос текстом. Тогда — список моделей получен из API, ответ стримится в оверлей, в provenance — provider, model, first_token_ms, «Цена неизвестна/0 (локально)».

AC-5: Дано — синтетический генератор реплик. Когда — `npm test` (1000 переходов: новые вопросы, уточнения, дубли, перебивания посреди генерации). Тогда — 0 случаев, когда ответ на устаревшую ревизию/вопрос стал активным в UI-модели; дубли в окне 20 с с похожестью > 0.85 не порождают запрос; уточнения порождают новую ревизию.

AC-6: Дано — CV без упоминания Kubernetes. Когда — собирается промпт на вопрос «Расскажите про опыт с Kubernetes». Тогда — в промпт попадают только top-k фрагменты CV с пометкой источника, есть явный запрет выдумывать опыт; бюджет токенов контекста не превышен (тест). Транскрипт в промпте — только последние N минут.

AC-7: Дано — whisper-server и WAV-файл с вопросом (TTS). Когда — прогон через ASRManager. Тогда — final-сегмент с source, start_ms/end_ms, text; задержка на короткую фразу с дефолтной моделью ≤ 1.2 с на этой машине (замер в логе диагностики).

AC-8: Дано — оверлей показан, фокус в другом окне. Когда — набор текста / нажатие хоткеев. Тогда — символы не попадают в оверлей, foreground не меняется; `setContentProtection` возвращает статус «включено/не поддерживается» в UI.

AC-9: Дано — процесс убит посреди сессии. Когда — повторный запуск. Тогда — сессия помечена `interrupted`, транскрипт и вопросы до момента сбоя на месте (WAL-журнал).

AC-10: Дано — лимит $1/сессию и известная цена модели. Когда — набегает стоимость ≥ лимита. Тогда — новые платные вызовы блокируются со статусом `budget_blocked` до подтверждения пользователя; провайдер не переключается сам (тест).

AC-11: Дано — пользователь нажал «Снимок области». Когда — выделил прямоугольник. Тогда — показано превью с кнопками «Отправить / Размыть область / Отмена»; без подтверждения ничего не отправляется; для модели без vision — локальный OCR или честное сообщение.

AC-12: Дано — включён Offline. Когда — любая попытка запроса на не-loopback адрес (из main и renderer). Тогда — запрос заблокирован и залогирован как `blocked_offline` (тест на сетевой guard + ручная проверка с отключённой сетью).

AC-13: Дано — сессия с транскриптом. Когда — «Удалить сессию» / «Удалить всё». Тогда — строки исчезают из всех таблиц (тест на SQLite), экспорт пуст.

AC-14: Дано — первый запуск. Когда — мастер: язык → устройства → ASR → LLM + проверка → профиль → тест → согласие. Тогда — все шаги проходимы, каждый шаг можно пропустить к дефолту; локальный путь (Ollama + whisper) не требует ключа.

## Non-goals
- Обход прокторинга, скрытие процесса, «невидимость» как обещание.
- Подписанный установщик и автообновление (нужен сертификат — P1), macOS/Linux.
- Облачные STT (OpenAI realtime / Gemini Live) — интерфейс адаптера есть, реализация в P1.
- Diarization участников внутри remote-канала.
